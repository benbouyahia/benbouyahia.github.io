# Hosting on Vercel

1. Connect this Lovable project to your GitHub account from the editor's GitHub settings.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Leave the project root as the repository root. The included `vercel.json` configures installation and build automatically.
4. Click **Deploy**.

The dedicated Vercel build uses Nitro's Vercel adapter and prepares the original public dashboard images and portrait for independent hosting. Normal Lovable preview and publish behavior remains unchanged. No database or private environment variables are needed.

Vercel deployment has not been performed or verified from this workspace. The image preparation step needs network access to the owner's public GitHub portfolio repository.
